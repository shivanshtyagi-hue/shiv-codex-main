# Shiv — Codex Coworking Workspace

This is the durable context layer for working with Codex and the Codex CLI.

## Start here

1. Read `Shiv/master_agent.md`.
2. Read the relevant files in `context/`, `projects/`, and `workflows/`.
3. Create or update a dated note in `sessions/` for substantial work.
4. Keep credentials out of this folder; document only where a connection is configured and what it is for.

## Directories

- `Shiv/`: the master operating brief
- `context/`: durable context about the user and current focus
- `workflows/`: repeatable ways of working
- `sessions/`: session memory and handoffs
- `projects/`: project briefs and project-specific context
- `integrations/`: tool and connector inventory
- `templates/`: reusable templates
- `archive/`: old or replaced material

## Planned evolution

This workspace can later become a Git repository. Before publishing it, review for secrets, private data, machine-specific paths, and anything that should remain local.
