# New Session

Use this at the beginning of a substantial session.

- [ ] Read `AGENTS.md`.
- [ ] Read `Shiv/master_agent.md`.
- [ ] Read current priorities and relevant project context.
- [ ] Identify the desired outcome and what “done” means.
- [ ] Create a dated session note if the work will span multiple turns.
- [ ] Confirm any external action that would be consequential or hard to reverse.
